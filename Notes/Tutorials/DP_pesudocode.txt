Comparsion between assignment types:
	1. := variable (sequential) assignment
		It's sequenial! 
	2. <= signal (concurrent) assignment
		Sequence doesn't matter here because it simulates the interconnection of circuit.
Example:

signal sig1, sig2, sig3: std_logic;

sig1 <= sig2 and sig3; 1.
sig3 <= sig1 and sig2; 2.


variable var1, var2, var3: std_logic;

var1 := var2 + var3; 
var3 := var1 - var2;

Origionally, var1 = '5', var2 = '6', var3 = '7'

1 -> 2: finally, var1 = 13, var2 = 6, var3 = 7;

2 -> 1: var1 = 5, var2 = 6, var3 = -1;
